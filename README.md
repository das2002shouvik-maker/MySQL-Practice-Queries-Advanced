# MySQL SQL Queries Practice

## About the Repository

This repository contains my MySQL practice queries, created to strengthen my understanding of SQL fundamentals and data manipulation. It includes exercises covering filtering, sorting, aggregation, grouping, subqueries, and window functions.

The goal of this repository is to improve my SQL problem-solving skills and build a strong foundation in database querying.

## Topics Covered

- **WHERE Clause** — Filtering records using conditions and logical operators.
- **ORDER BY** — Sorting query results in ascending and descending order.
- **LIMIT** — Restricting the number of rows returned.
- **Aggregate Functions** — Using `COUNT()`, `SUM()`, `AVG()`, `MIN()`, and `MAX()`.
- **GROUP BY** — Grouping records to perform aggregate calculations.
- **HAVING Clause** — Filtering groups based on aggregate conditions.
- **LIKE Operator** — Searching for patterns in text.
- **UPDATE and DELETE** — Modifying and deleting records.
- **Subqueries** — Solving problems using nested queries and correlated subqueries.
- **Window Functions** — Using `ROW_NUMBER()`, `RANK()`, and `DENSE_RANK()`.
- **Combined Queries** — Applying multiple SQL clauses to solve practical problems.

## Tools Used

- MySQL
- MySQL Workbench

## Practice Highlights

Some of the problems covered in this repository include:

- Finding the average salary of employees above a specified age.
- Calculating department-wise average and total salaries.
- Counting employees in each city.
- Identifying employees earning above their department's average salary.
- Finding the second-highest salary without using `LIMIT`.
- Retrieving the top three highest-paid employees in each department.
- Updating salaries based on city-wise average salary.
- Filtering departments using aggregate conditions.

## Learning Objectives

- Develop a clear understanding of SQL query execution and filtering.
- Apply aggregate functions with `GROUP BY` and `HAVING`.
- Solve practical database problems using subqueries.
- Improve query-writing and analytical skills.
- Practice data manipulation using `UPDATE` and `DELETE`.
